## Когда манифесты попали в историю

Оба файла впервые добавлены в Git коммитом `850aeb74b635d91a53a6730807995675ad27d967` от `2026-10-25T07:59:43+03:00`. С этого коммита их содержимое не менялось. Тег на него — `freeze-manifests-20261025`.

Теги созданы при подготовке публикации и указывают на существующие коммиты. История не переписана, даты тегов не менялись задним числом. Поле `time` в манифесте и даты коммитов отражают локальную хронологию; они не являются независимой серверной отметкой времени заморозки. Публикация на GitHub фиксирует наличие этой истории с момента загрузки.

## Проверка

Из корня клона, без загрузки моделей:

```bash
git show --no-patch --format=fuller freeze-oot-code-20261025^{commit}
git show --no-patch --format=fuller freeze-post-oot-code-20261025^{commit}
git log --diff-filter=A --format=fuller -- artifacts/freeze.json artifacts/freeze_post_oot.json
git rev-parse HEAD:artifacts/freeze.json HEAD:artifacts/freeze_post_oot.json
git diff freeze-manifests-20261025 HEAD -- artifacts/freeze.json artifacts/freeze_post_oot.json
python scripts/verify_freeze.py
```

Пустой вывод `git diff` означает, что содержимое манифестов не менялось с их добавления. SHA-1 выше — идентификатор Git blob; SHA-256 рассчитан по содержимому файла. Переводы строк LF/CRLF дают разные SHA-256, поэтому приведены оба варианта. Манифесты также содержат первые 16 символов SHA-256 всех 19 чекпойнтов; при наличии локальных файлов их проверяет `python scripts/verify_freeze.py --checkpoints`.
